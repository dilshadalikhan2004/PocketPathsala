# LENTERA 2.0 — HACKATHON GRAND FINALE DEMO SCRIPT

## Demo Flow 1: Offline Multimodal Tutor
1. Open LENTERA on iQOO smartphone in Airplane Mode (Wi-Fi OFF, Mobile Data OFF).
2. Tap **Scan & Learn**. Point camera at textbook page on *Refraction of Light*.
3. System detects document, performs OCR, maps topic to *CBSE Class 10 Science - Light*.
4. Tap **Teach Me**. Receive instant grounded explanation with source attribution.
5. Tap Microphone or Ask: *"Explain this like I'm in class 8."* System returns a simplified explanation.
6. Tap **Practice**. Take quiz on *Refraction*. Deliberately answer a question wrong.
7. System identifies weak concept (*Refraction in Lenses*) and recommends a 5-minute remedial lesson.
8. Complete remedial lesson and re-take question. Mastery improves from 41% → 68%.

## Demo Flow 2: Socratic Problem Solver
1. Tap **Scan & Learn** -> **Solve Problem**. Point camera at optics numerical equation.
2. System extracts formula ($1/f = 1/v - 1/u$).
3. Tutor asks: *"What is the lens formula convention for focal length of a concave lens?"*
4. Student answers. System evaluates response and guides step-by-step to final solution.

## Demo Flow 3: Local Classroom
1. Teacher opens **Classroom** -> **Create Room**. Generates room code `849201`.
2. Student devices tap **Join Room** and connect via local Wi-Fi/Hotspot.
3. Teacher launches live 3-question quiz.
4. Students submit answers. Teacher receives instant submission analytics & class weak concept breakdown.
5. Teacher broadcasts AI remedial explanation to all student screens.
